Nextlevel Gems

A modern product catalog web app for showcasing gemstones.
Includes category filtering, product detail pages, and a media gallery with image + video support.

Live: https://nextlvlgem.com

Overview

Nextlevel Gems is a frontend application built for presenting gemstones in a clean and structured way.
The app contains a full product listing page with search and filtering, and a product detail page with a carousel gallery.

Features
Product catalog (All Products)
Search inside products
Category and subcategory filtering (URL-driven)
Product detail page
Media gallery (images + Vimeo / YouTube embeds / video files)
Responsive layout

Tech Stack
Vue 3
TypeScript
Vite
Vue Router
Tailwind CSS
Vercel (deployment)
